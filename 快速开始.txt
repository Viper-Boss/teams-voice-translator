Teams 双向课堂翻译与答辩助手 v1.14.8
=============================

一、安装 VB-CABLE
打开 https://vb-audio.com/Cable/ 安装 VB-CABLE，之后重启 Windows。

二、程序设置
1. 运行 TeamsVoiceTranslator.exe。
2. 填写百炼北京地域的 Workspace ID 和 API Key，并测试连通性。
3. 确认业务空间已授权：
   - qwen3.5-livetranslate-flash-realtime（极速直译）
   - qwen3-asr-flash-realtime（识别）
   - qwen-mt-flash（翻译）
   - qwen3-tts-vc-realtime-2026-01-15（实时 TTS）
   - qwen3-tts-vc-2026-01-22（高清 TTS）
   - qwen-voice-enrollment（Qwen3 声音复刻）
   可选：fun-asr-realtime、qwen-audio-3.0-tts-plus、qwen-audio-3.0-tts-flash、cosyvoice-v3-flash、cosyvoice-v3.5-plus、voice-enrollment。
4. 物理麦克风：选择你的真实麦克风。
5. Teams 虚拟输出：选择 CABLE Input。
6. 老师/Teams 系统声：选择与 Teams 扬声器相同的 [Loopback] 设备。
7. 点击“运行音频设备诊断”，然后保存全部设置。

三、Teams 设置
麦克风选择 CABLE Output，扬声器选择你的耳机。

四、开始双向会议
点击“开始听老师 / Teams”：老师英文会显示英文原文和中文字幕。
按住 F8：你的原声立即发给 Teams，同时生成中英字幕。
按住 F9：说中文，松开后翻译并用英文音色发给 Teams。
如需免按键，勾选“F9 持续翻译”，再按一次 F9 开启；程序会检测停顿并自动逐句翻译。再次按 F9 停止。
持续翻译中按住 F8，会自动关闭 F9 并切换为 F8 原声。
按 Esc：立即停止，并关闭老师监听。

五、F9 极速模式和传统模式
默认“极速直译”由 Qwen3.5 LiveTranslate 直接输出中文字幕、英文字幕和英文语音，延迟更低，并固定自动流式发送。
首次使用请选择“服务端复刻一次（推荐，无需上传样音）”。第一段用于建立音色校准，可能暂时使用默认过渡音色；保持程序开启，第二段及后续会复用你的音色。
百炼当前可能拒绝为 Qwen3.5 LiveTranslate 预创建固定音色；固定 voice_id 仅供已有兼容音色的高级用户使用。
如需先确认、翻译记忆或表达风格，可切换“传统模式”。
传统模式可选择 Qwen3-TTS-VC 实时版（低延迟）或高清版（更自然）作为 TTS 模型；两种模型需要分别创建克隆音色，程序会按模型自动保存和切换。
传统模式也兼容 Qwen-Audio 和 CosyVoice；CosyVoice v3.5-plus 克隆最像本人。
传统模式如需克隆音色，可点击“创建克隆音色”并选择本地录音；Qwen3 复刻不需要 OSS，Qwen-Audio/CosyVoice 需要配置 OSS。
传统模式的“发送方式”可选择立即发送，或先确认/编辑。
确认模式下修改英文后，点击“播放/发送当前英文”。
历史记录双击一行可重新载入并重播；点击每句后的 ▶ 可重播该句语音。

六、键盘输入
输入中文后按 Enter 翻译并发送。
Ctrl+Enter 或 Shift+Enter 换行。

七、使用 VoiceStudio 本地声音
打开“本地声音工作台 → 运行管理”，可选择安装路径并自动下载安装，下载阶段会显示百分比。
也可导入本地 MSI；程序会自动拉取 GitHub 最新版本和 SHA-256，一致显示绿色，不一致红色警告但允许人工确认后安装。“手动下载”会直达 GitHub 官方 Releases。
同一页可安装、卸载、启动、停止、重启和升级，并查看已安装/API/最新版本及后台进程。正常进程显示绿色，API 异常显示红色。
先在 VoiceStudio 内完成首次模型下载和声音克隆，再回本程序点“检测并同步”。
选好模型和声音后先点“仅在本机试听”，确认无误再点“设为当前语音后端”。
传统 F9、键盘发声、历史重播和整段朗读会使用本地声音；极速 F9 仍使用百炼实时音频。

八、录音
点击“开始录音”会保存三份 WAV：
1. 你的麦克风；2. 老师/Teams 系统声；3. 双方混合会议。
录制他人声音前请征得对方同意。

九、字幕和总结
字幕后台始终完整缓存中文、英文、说话人和时间。
保存时可选语言，以及 SRT/TXT/WebVTT/Markdown/JSONL 等格式。
“生成课堂总结”可整理知识点、老师回答、作业待办和术语。

十、课程配置
可用表格编辑专业术语，并按课程保存翻译领域、术语、表达风格、音色和 TTS 指令。
