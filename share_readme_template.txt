留子答辩器 · 分享版 v{VERSION}
专门为留学生开会和答辩准备的 Windows 双向语音辅助工具

一、打开程序
完整解压全部文件，再运行 DefenseMode\DefenseMode.exe；不要只复制 EXE。
请核对软件来源与发布版本。遇到系统安全提示时，先确认文件来源，不要直接关闭安全软件。

二、自己准备账号和设备
需要自己的阿里云百炼账号、可用的模型权限、匹配的音色、麦克风和耳机。
云端识别、翻译、生成、合成和复刻可能产生费用，费用记在自己的账号上。
在“设置”中填写 Workspace ID 和 API Key，测试连接并试听自己的声音。

三、连接会议
VB-CABLE 驱动另行安装：https://vb-audio.com/Cable/
软件程序输出选 CABLE Input；会议麦克风选同一条线的 CABLE Output。
会议扬声器选耳机；软件评委回环选该耳机对应的 [Loopback]。
本机试听可以使用另一条独立输出，避免试听再次进入评委识别。

四、操作
默认 F8 原声、F9 翻译、Esc 停止当前发声，快捷键可在设置里修改。
勾选“持续监听”后按一次开始、再按一次停止；未勾选时按住说话、松开停止。
讲稿和问答提前渲染、回听；AI 答案需结合自己的研究核对。

五、录音与数据
勾选自动录音后，开始答辩并确认老师录音时长在增长。
老师原声：记录文件夹\录音\teacher_system_*.wav。
“保存英文语音”保存的是软件合成语音，不是老师原声。
默认会议记录在文档\DefenseMode；配置、讲稿、问答与缓存位于 %APPDATA%\TeamsVoiceTranslator。
使用云模型时，相应音频、文本或论文上下文会发送给所选服务。
请按学校和会议要求使用录音及 AI 辅助，并取得相关参与者同意。

六、问题反馈
说明软件版本、设备路由、复现步骤和错误提示。
日志和截图先检查、脱敏；不要公开密钥、论文、录音、整个数据目录或内存快照。
